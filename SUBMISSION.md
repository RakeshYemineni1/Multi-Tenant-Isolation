# Submission Instructions

Please follow the steps below to submit your solution.

---

## How to submit

1. Create a **new GitHub repository in your own account**
   - You may keep this repository **private or public**
2. Implement the solution according to `TASK.md`
3. Ensure your project can be run using:
   docker compose up --build
4. Submit your work by replying to the email where you received this task with:
   - A link to your repository **OR**
   - A ZIP archive of your project

---

## Notes

- Do not include any private credentials or secrets
- Include a README explaining:
  - How to run the project
  - Key design decisions
  - Assumptions and trade-offs
- Partial solutions are acceptable if explained clearly

---

Thank you for taking the time to work on this assignment.
